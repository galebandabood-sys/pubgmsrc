# NOVA 2.0 — منيو عائم مستقل للأندرويد

هذه نسخة APK قابلة للتثبيت، مخصصة لعرض فقاعة صغيرة ومنيو فوق التطبيقات التي تسمح بالـ Android System Overlay. ليست هاك ببجي ولا تقوم بأي تعديل في ذاكرة اللعبة.

## ميزات المنيو الفعلية
- فقاعة باسم N يمكن تحريكها باللمس وتغيير مكانها.
- ضغط الفقاعة لفتح أو تصغير منيو NOVA فوق التطبيقات.
- ساعة حقيقية، مع التحكم بإظهارها.
- مؤقت تركيز يعمل لـ 5 دقائق مع زر لإضافة دقيقة وإيقافه.
- تغير اللون والشفافية مع حفظ الإعدادات محلياً.
- إشعار دائم فيه زر إيقاف؛ خدمة Foreground لتقليل إيقاف الفقاعة.
- زر فتح PUBG Mobile العالمية وبعض الحزم الشائعة **إذا كانت مثبتة**، أو تشغيلها يدوياً من شاشة الهاتف.
- عرض اسم حزمة PUBG المثبتة ورقم إصدارها من نظام أندرويد، من دون الدخول إلى عملية اللعبة.
- إصلاح زر الإيقاف حتى لا يبدأ خدمة الفقاعة إذا كانت متوقفة، وإبقاء الفقاعة ضمن حدود الشاشة عند استرجاع موقعها.
- طلب إذن الظهور فوق التطبيقات من خلال شاشة النظام، بلا روت.

## طريقة الاستخدام
1. ثبت `app-debug.apk` الناتج من GitHub Actions (الإصدار 2.1).
2. افتح NOVA واختر «السماح بالظهور فوق التطبيقات»، ثم فعّل الإذن.
3. ارجع إلى NOVA واختر «تشغيل الفقاعة العائمة».
4. افتح ببجي من داخل NOVA أو من شاشة الهاتف.
5. إذا سمح النظام واللعبة بإظهار التطبيقات العائمة، ستشاهد فقاعة N، ويمكنك سحبها والضغط لفتح المنيو.
6. للإغلاق: اضغط «إيقاف المنيو» أو «إيقاف» من إشعار NOVA.

## الحدود
- أحدث نسخة رسمية وقت مراجعة المشروع (15 نوفمبر 2026) هي PUBG Mobile 4.7. **هذا لا يعني أن المنيو مجرَّب أو مضمون فوقها**؛ الطبقات العائمة تعتمد على النظام/إعدادات الهاتف وسياسة اللعبة وقد تُحظر.
- المنيو لا يعمل داخل عملية ببجي، بل في نافذة أندرويد منفصلة فوقها.
- لا يوجد ESP، Aimbot، تغيير سكنات، تعديل بيانات اللعبة، تخطّي Anti-Cheat أو إخفاء هذه التعديلات.
- نجاح بناء APK في GitHub Actions لا يعادل اختباراً فعلياً على جهازك أو داخل اللعبة.
- مشروع `app/` القديم وملفات C++ الأصلية لم يتم تغييرها.

## بناء APK
يُبنى من مسار `nova-demo` باستخدام GitHub Actions باسم `NOVA Floating Overlay APK`.
إذا كانت النتيجة Success، نزّل `NOVA-floating-menu-apk` من Artifacts، وفك الضغط لتجد APK.

التصميم والشفافية والساعة والمؤقت ميزات Android حقيقية وليست أزراراً شكلية.
