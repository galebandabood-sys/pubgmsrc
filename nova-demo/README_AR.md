# NOVA | نسخة الأندرويد التجريبية

واجهة عربية داكنة يمكن تثبيتها كتطبيق مستقل على أندرويد. تدعم:
- تبويبات الرئيسية والمظهر والخصوصية وحول.
- أربعة ألوان للواجهة وخيار النص الكبير والتخطيط المدمج.
- تخزين الإعدادات محلياً بواسطة SharedPreferences.
- خيار منع لقطات الشاشة داخل تطبيق NOVA باستخدام FLAG_SECURE.
- خيار إبقاء شاشة التطبيق شغّالة.
- عدم طلب أي صلاحيات خطيرة أو الاتصال بالشبكة.

## مهم جداً
هذه **نسخة تجريبية مستقلة** من المنيو. ليست ببجي موبايل، ولا تتصل بعملية اللعبة ولا تُحمّل كوداً إليها. ليس فيها ESP أو Aimbot أو Bypass، ولا نؤكد توافق المصدر الأصلي مع إصدار جديد.

## تنزيل APK من GitHub
1. ادخل على تبويب **Actions** في مستودعك.
2. افتح التشغيل الناجح باسم **NOVA Android demo APK**.
3. انزل إلى **Artifacts** ونزّل **NOVA-demo-debug-apk**.
4. فك الضغط عن الملف ZIP لتحصل على **app-debug.apk** ثم جرّبه على جهازك.

قد يطلب GitHub تفعيل Actions أول مرة. إذا فشل البناء، افتح سجل الخطأ (Logs) قبل تجربة التثبيت.

## البناء محلياً
هذه وحدة Gradle منفصلة عن التطبيق الأصلي، حتى لا تتعارض تعديلات اللعبة أو SDK القديم مع التجربة.

يتطلب Java 11، Gradle 7.0.2، Android SDK Platform 31، Android Gradle Plugin 7.0.3.

```sh
gradle -p nova-demo assembleDebug
```

الناتج بعد نجاح البناء:
`nova-demo/app/build/outputs/apk/debug/app-debug.apk`

لا توجد تبعيات Java أو صلاحيات أندرويد إضافية.
